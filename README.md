# sql_retail_sales_analysis_project
# Retail Sales Analysis Using SQL Server

## Project Overview
Analyzed retail sales data using SQL Server to identify sales trends, customer purchasing behavior, and product performance.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## SQL Concepts
- Joins
- Aggregate Functions
- GROUP BY and HAVING
- CTEs
- Window Functions
- CASE Statements
- Date Functions

## Objectives
- Analyze monthly and yearly sales.
- Identify best-selling categories.
- Find the best-selling month in each year.
- Analyze customer purchasing patterns.
